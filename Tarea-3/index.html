Diseño web responsivo

Permite que una misma página se adapte a cualquier tamaño de pantalla, ya sea celular, tablet o computadora.

Viewport

Es el área visible de la página. Se configura así:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

CSS3 Media Queries

Aplican estilos según el tamaño de la pantalla.

@media (max-width: 768px) {
    .layout { flex-direction: column; }
}
